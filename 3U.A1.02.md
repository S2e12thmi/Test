# 📂 Activity 1.02 - Computer Architecture & Memory Hierarchy

## 🎯 Activity Overview
Understanding internal hardware components, system metrics, and peripheral connectivity is essential for matching computer hardware to user requirements. This activity reinforces your knowledge of core processing hardware, primary vs. secondary storage, system buses, and peripheral hardware selection.

## 🛠️ Part A: Core Internal Component Identification
Match each internal hardware component to its primary role in the system.

### 1. Component Matching
Write the letter of the correct description next to each component:

* **CPU:** `_____`
* **RAM:** `_____`
* **ROM:** `_____`
* **Cache Memory:** `_____`
* **Motherboard:** `_____`
* **Power Supply Unit (PSU):** `_____`
* **Video Card (GPU):** `_____`
* **Sound Card:** `_____`

**Descriptions:**
* **A.** Dedicated hardware expansion card responsible for processing 3D visual graphics and rendering display outputs.
* **B.** The main circuit board containing physical pathways (buses) to connect and route power/signals between all components.
* **C.** Temporary, volatile working memory where active code and data live during execution.
* **D.** Non-volatile memory containing permanent boot instructions (like BIOS/UEFI).
* **E.** Converts wall outlet AC power into regulated, low-voltage DC power for internal components.
* **F.** The "brain" of the computer that fetches, decodes, and executes program instructions.
* **G.** Processes digital audio signals into analog sound output for speakers/headphones and converts microphone inputs into digital data.
* **H.** Ultra-fast, tiny memory pool located on or adjacent to the CPU chip to store frequently accessed instructions.
